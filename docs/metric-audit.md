## 1. Metric Classification Matrix

Every metric reported by the evaluation engine and quality gate has been audited and classified into:
- **REAL / ACTUALLY MEASURED**: Measured against live PostgreSQL database queries, real document parsers, real HTTP API calls, or live infrastructure.
- **MOCK / FALLBACK / DETERMINISTIC**: Generated by local deterministic fallback handlers when external cloud API keys are unconfigured.
- **SIMULATED**: Calculated using synthetic/academic benchmark baselines or heuristic rule checks.
- **UNVERIFIED**: Not backed by direct empirical measurement.

### Code Execution Path:
1. **Embedding Service (`backend/app/rag/embedding_service.py`)**:
   - Because `EMBEDDING_API_KEY` is not set, `_deterministic_768_embedding()` is invoked.
   - It computes a normalized SHA-256 trigonometric float vector of exactly **768 dimensions**.

3. **Diagnostic Service (`backend/app/ai/diagnostic_service.py`)**:
   - Because `LLM_API_KEY` is not set, `_generate_grounded_fallback()` is invoked.
   - It directly takes the multi-source context (asset meta, error code rows, retrieved chunks, maintenance records) and synthesizes a grounded `DiagnosticOutputSchema` with real database citations and safety rules.
